# משימות פתוחות ורעיונות

## פתוח עכשיו
1. **לוגואים אמיתיים לקבוצות ולנבחרות.** ביקשו אותם, אבל אי אפשר היה להוריד אותם, כי סביבת הענן של Claude חוסמת את רוב האינטרנט.
   - **איך משיגים:**
     - (א) בהגדרות הסביבה של Claude Code מוסיפים לרשימת הגישה את `upload.wikimedia.org` ואת `he.wikipedia.org`, ואז מבקשים מ־Claude להוריד, או
     - (ב) שולחים תמונות של הלוגואים בצ'אט, או
     - (ג) מורידים בעצמכם ושמים בתיקייה `assets/logos/<id>.png`. ה־`id` הוא מהקובץ `js/clubs.js`, למשל `nes-ziona.png`.
   - **איפה להציג:**
     - **בכרטיסים** (מסך הקבוצות): ב־`drawMini` ב־`js/main.js`, עם `drawImage` על ה־canvas הדו־ממדי.
     - **בלוח התוצאות:** `<img>` ליד השם.
     - **על החולצה במשחק** קשה יותר. המנוע מצייר רק צורות, ולכן כנראה עדיף להשאיר שם את הסמל המצויר.
   - **שימו לב:** הלוגואים שייכים למועדונים ולאיגודים, והאתר ציבורי.
   - **לא לשכוח:** להוסיף את הקבצים ל־`CORE` ב־`sw.js`.
2. **צבעים שלא אומתו.** בחיפוש אומתו רק כמה צבעים:
   - נס ציונה כתום.
   - מכבי ראשון לציון צהוב.
   - גרמניה לבן בבית ושחור בחוץ.
   - ישראל כחול־לבן.

   בשאר הקבוצות הצבעים "מקובלים" (הפועל באדום, מכבי בצהוב־כחול). מי שמכיר יכול לתקן ב־`js/clubs.js` (`kit(...)` ו־`CRESTS`). אחרי כל שינוי צבע מריצים בדיקות: הבדיקות מוודאות שבכל משחק החולצות של שתי הקבוצות שונות.
3. **רשימת ליגת הילדים.** הרשימה מבוססת על ליגת העל, ולא על ליגת הילדים עצמה (לא הייתה גישה לאתר האיגוד). אפשר להוסיף או להוריד קבוצות ב־`CLUBS`, בתוספת סמל ב־`CRESTS`.
4. **כוחות "טבעיים".** הכוח הטבעי של אמה (אש) ושל רפל (קפטן) הוא ניחוש שהילדים לא אישרו. הוא משפיע רק על התחפושת בכרטיס.

## רעיונות שעלו בדרך (לא חובה)
- **שוער:** אפשרות שילד יהיה שוער, למשל כפתור "שוער" על כרטיס הילד. לא להחזיר את עורך העמדות המלא.
- **שני שחקנים:** שני ילדים על אותו טלפון או בשני טלפונים.
- **טורניר:** כמה משחקים ברצף מול קבוצות שונות, עם טבלה.
- **עוד כוחות:** למשל כוח רוח או מגנט.
- **חגיגות גול:** חגיגות לכל ילד.

## איך להוסיף ילד חדש מתמונה
1. מסתכלים על התמונה ומחליטים על הפרמטרים: עור, צבע שיער ובהיר שיער, גבות, עיניים, סגנון שיער, משקפיים, נמשים, חיוך ועגילים.
2. מוסיפים פרופיל ל־`PROFILES` ב־`js/heroes.js`, עם `id`, `nameHe` ו־`power`.
3. סגנון שיער חדש מוסיפים בשני מקומות: `drawPortrait` (התמונה הגדולה) ו־`drawHairFront` ב־`js/toon.js` (השחקן הקטן).
4. **לא שומרים את התמונה בריפו.**
5. מריצים `npm test` ואת `npm run e2e`. הבדיקות בודקות שיש בדיוק 4 ילדים, ולכן צריך לעדכן את הבדיקה ב־`tests/e2e.mjs` (החלק `flow`).
